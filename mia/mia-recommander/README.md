# MIA Recommander

Jeu d'arcade de démo : le joueur classe 5 clients selon qu'ils vont augmenter ou non leur versement 111bis (plafond 3 200 € → 4 500 €), contre la montre. Son temps est projeté sur l'ensemble du foyer ciblé (50 000 clients) face à MIA, puis un classement s'affiche.

- Page unique : `index.html`, sans build ni dépendance.
- Version jouable : https://claude.ai/artifact/XjTJfUr7CtSpFKb2yz9Bi8
- Le trigramme (une seule partie par joueur) et le classement utilisent la base de données des artifacts claude.ai. Ouverte ailleurs, la page s'affiche mais refuse de lancer une partie.
- Les clients sont fictifs.
